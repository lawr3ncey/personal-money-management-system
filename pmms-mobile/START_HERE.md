# 🚀 Quick Start - React Native Mobile App

## Start Development Server

**Double-click this file:**
```
start-expo.bat
```

**Or run in terminal:**
```powershell
cd pmms-mobile
.\start-expo.bat
```

## Test on Web
1. Wait for QR code to appear
2. Press `w` key
3. Browser opens at: http://localhost:8082
4. Login with: demo@6jars.com / demo123

## Test on Mobile
1. Install "Expo Go" app on your phone
2. Connect to same WiFi as your computer
3. Scan the QR code from terminal
4. App loads on your device

## Common Commands
- `w` - Open web browser
- `a` - Open Android
- `i` - Open iOS (Mac only)
- `r` - Reload
- `Ctrl+C` - Stop server
